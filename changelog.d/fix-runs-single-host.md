- **One host for background runs.** Only one Chanto process at a time hosts background runs and scheduled jobs. A `chanto web` or `chanto serve` started while the daemon is up now serves sessions only, instead of marking the daemon's live runs interrupted, starting its queued runs a second time, firing scheduled jobs twice and taking over the daemon's connection file. Two `chanto run --bg` commands started together share one daemon instead of each starting their own.
- **Unpushed runner work is kept.** When `chanto runner connect` can't push a finished run's branch, the run's worktree and branch now survive the runner's next start, instead of being deleted with the only copy of its commits. The runner says where they are when it starts.
