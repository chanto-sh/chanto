- **`chanto team resume` merges only finished work.** A team stopped while it waited for a sub-task it had re-delegated after a conflict could, on resume, merge that sub-task's half-done work while its agent was still running, and never merge the rest. Resume now waits for the run and reviews it first, and a run that stopped unfinished is reported as failed instead of merged.
- **Safer `chanto upgrade`.** The new binary is written to disk and then renamed over the old one in a single step, so an interrupted or failed upgrade can no longer leave you without a `chanto` binary. On Windows, if the new binary can't be put in place, the old one is moved back.
