- **Waiting on a background command.** `BashOutput` with `wait_secs` returned as soon as a command printed anything, so a test run printing a dot per test ended every wait at once and the model polled again and again: 60 polls and the full 30-minute limit in one benchmark task. It now waits until the output has settled for a few seconds, the command exits, or (with `filter`) a matching line appears.
