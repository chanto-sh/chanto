- **Faster start and turns.** A one-shot run uses about 19% less CPU to start and each model turn about 11% less. Secret masking no longer falls back to the regex engine's slowest path on text with a non-ASCII character (one em dash was enough), no longer compiles its costliest patterns for text they can't match, and checks for its two special case-folding characters with a fast search. Chanto also starts at most four async worker threads instead of one per core (`TOKIO_WORKER_THREADS` still sets the count), and `CHANTO_TIMING` now shows the CPU used at each checkpoint.
