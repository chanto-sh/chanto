# Editor integrations

> [!WARNING]
> **Not ready yet.** The editor integration is a work in progress: it isn't documented or
> supported, and it may change or break without notice. For now, use Chanto
> from the terminal.

`vscode/` and `jetbrains/` are editor plugins that connect to a running Chanto TUI over the localhost bridge described in [PROTOCOL.md](PROTOCOL.md).
