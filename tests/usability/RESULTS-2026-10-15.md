### Fixes

- Setup picker: section headers aren't selectable rows; long choices wrap. Gateway "invalid model" errors point at `chanto models <provider>`; `doctor` says a key was rejected rather than "unreachable".
- Verified mode: no tests found is ⚠ Not verified; pytest found through `python` when `python3` lacks it; a pre-existing failing check is named; acceptEdits denials suggest auto mode or an allow rule.
- TUI: `/rewind undo` works; the resume hint survives exit; free-text questions accept typing at once; `/model` lists each Ollama model once.
- Bash: a connection failure under `network = "deny"` says the sandbox blocked it.

### Not fixed

- Verified mode's reminder ("You can't finish until they pass") pushes the model past explicit instructions: told "don't change remove()", it fixed a pre-existing bug in remove() to get green (it did flag the deviation).
- `-p` exits 0 when the answer ends ⚠ Not verified, so scripts can't tell.
- Custom OpenAI-compatible providers default to a 32k context even when the server reports more (LiteLLM: 1M), so long sessions compact early unless `num_ctx` is set.
- Markdown soft line breaks are joined, so line-per-item output without list markers renders as one paragraph.
- `--base-url` is silently ignored with a built-in `provider/model`.
- Fixed-choice questions (Allow/Deny, Send/Decline, yes/no) still offer "Type something else…".
- Web UI sidebar shows session ids only.
